# SunuTask - Flutter L3GL-ISIKM 2025-2026

## ⚠️ COMMENT OUVRIR (IMPORTANT)

**Erreur fréquente** : "Expected to find project root in current working directory"
→ Cela signifie qu'Android Studio est ouvert sur le MAUVAIS dossier.

### Solution :
1. Décompressez le zip → vous obtenez un dossier `sunu_task/`
2. Android Studio → **File > Open**
3. Sélectionnez le dossier `sunu_task` (celui qui contient `pubspec.yaml`)
4. Cliquez **OK / Open**
5. Dans le terminal : `flutter pub get`
6. Lancez avec **Run ▶**

> Le dossier correct contient : `pubspec.yaml`, `lib/`, `android/`, `ios/`
